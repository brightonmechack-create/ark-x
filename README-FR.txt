ARK X - Application de trading (mode DEMO)

FICHIERS DU PROJET
- index.html          : toute l'application (design + code)
- manifest.json       : permet d'installer l'app sur le telephone
- service-worker.js   : garde l'app disponible hors connexion
- icon.svg            : icone de l'application

COMMENT TESTER
1. Ouvrir index.html dans SPCK Editor.
2. Appuyer sur le bouton vert "Lancer" pour voir l'apercu.
3. Creer un compte, choisir COMPTE DEMO, puis essayer Trade.

FONCTIONNEMENT
- Compte DEMO : 10 000 USD virtuels, achat, vente et conversion.
- Commission : 2 % uniquement sur le benefice d'une vente.
- Retraits : simules (Mobile Money, banque, carte).
- COMPTE REEL : bientot disponible, il faut un partenaire de paiement.
- Prix et graphiques : en direct via Binance. Sans connexion,
  l'application simule les mouvements (message "SIMULATED").

IMPORTANT
- Les comptes sont gardes uniquement dans le telephone.
  Pour de vrais utilisateurs, il faut le backend (dossier backend).
- Ne jamais mettre d'argent reel sans partenaire agree,
  verification d'identite (KYC) et autorisations legales.
